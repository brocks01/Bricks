# WhatsApp · Iteration 3.1 — Judge Path Live

Phase 3 (Hackathon) · **H0–H8** (≈ Sat 14 Nov 17:00 → Sun 01:00 SGT, SMU) · Est. ~1.5 h
Source: `06` §8 Phase 3 · `07` §6 Iteration 3.1

## 1. At a glance

| | |
|---|---|
| **Goal** | Any judge can scan a QR and experience Kampung Connect on WhatsApp in under a minute, with no app install |
| **Exit** | QR → WhatsApp → onboarding → **check-in arrives immediately** → No → join walk → group link, verified on 2 fresh phones |

## 2. Tasks

### 2.1 QR codes
| QR | Encodes | Route |
|---|---|---|
| Walk-up judge | `https://wa.me/<sandbox_number>?text=join%20<code>` | Twilio sandbox |
| Pre-registered judge | `https://wa.me/<meta_test_number>?text=Hi` | Meta test number |

- Print / put them on the slide next to the app QRs and the phone number.
- Pre-register judges' numbers on the Meta test number when they're shared (recipient limit permitting).

### 2.2 Judge-friendly flow
- After onboarding: send the check-in **right away** (not at 08:00): "Let's try it now. Did you move yesterday?" [Yes] [No].
- Seed walks near SMU / the city for judges (with B), so "No" always has a suggestion.
- Keep the onboarding to 3 questions max for judges (language, name, interests; area defaults to the venue).

### 2.3 Venue checks
- Delivery latency on venue Wi-Fi vs mobile data.
- Webhook host warm (keep-alive ping), so the first message isn't slow.

## 3. Test cases

| # | Case | Expected |
|---|---|---|
| T1 | Fresh phone scans the walk-up QR | Joins the sandbox → onboarding starts |
| T2 | Completes onboarding | Check-in arrives within seconds |
| T3 | No → Join walk | Venue-area walk + group link |
| T4 | "HELP" from a judge account | SOS reply; fan-out goes to **demo helpers only**, never to real strangers |

## 4. Definition of Done
- [ ] Both QRs verified on fresh phones
- [ ] Judge flow < 1 minute to the first check-in
- [ ] Judge SOS sandboxed to team helper phones
