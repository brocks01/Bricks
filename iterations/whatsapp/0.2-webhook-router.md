## 2. Tasks

### 2.1 Webhook — `channels/whatsapp/webhook.py`
```python
@router.get("/wa/webhook")                       # Meta verification handshake
def verify(hub_mode: str, hub_verify_token: str, hub_challenge: str):
    if hub_mode == "subscribe" and hub_verify_token == settings.WA_VERIFY_TOKEN:
        return PlainTextResponse(hub_challenge)
    raise HTTPException(403)

@router.post("/wa/webhook")
async def receive(request: Request):
    body = await request.body()
    verify_meta_signature(body, request.headers["X-Hub-Signature-256"], settings.APP_SECRET)
    for msg in parse_meta(body):                 # → InboundMessage(id, from, type, text, payload, media_id, location)
        if await seen(msg.id):                   # idempotency: store message.id
            continue
        await route(msg)
    return {"ok": True}                          # respond fast (< 5 s); heavy work in background tasks

@router.post("/wa/twilio")                       # sandbox route, same InboundMessage
async def receive_twilio(request: Request): ...  # validate X-Twilio-Signature
```
- Meta console → WhatsApp → Configuration → callback URL `https://<host>/wa/webhook` + verify token → subscribe to `messages`.
- Twilio sandbox → "When a message comes in" → `https://<host>/wa/twilio`.

### 2.2 Router — `channels/whatsapp/router.py`
| Type | Source field | Routes to |
|---|---|---|
| `text` | `text.body` | distress check → active flow (`wa_session`) → keyword (HI, MENU, HELP, STOP, START) → orchestrator (2.1+) |
| `button_reply` | `interactive.button_reply.id` | payload handler, e.g. `checkin:yes:2026-11-15`, `join:e_12`, `sos:onway:s_7`, `invite:yes:i_3` |
| `list_reply` | `interactive.list_reply.id` | active flow step (language, interests, menu) |
| `audio` | `audio.id` (ogg / opus) | media download → STT (2.2) |
| `location` | `location.latitude/longitude` | SOS / nearby events (2.2 / 3.2) |

Payload format: `<action>:<arg>[:<arg>]`, always ≤ 256 chars.

### 2.3 Session state
```sql
wa_sessions(user_phone PK, flow TEXT, step TEXT, data JSONB, expires_at TIMESTAMPTZ)  -- 30-min expiry
wa_seen(message_id PK, at TIMESTAMPTZ)                                                -- idempotency
```

### 2.4 Sender skeleton — `channels/whatsapp/sender.py`
`send_text`, `send_buttons(to, body, [(id, title)×≤3])`, `send_list(to, body, button, sections)`, `send_template(to, name, lang, params, buttons_payloads)`, `send_audio`, `send_location_request`, with a provider interface (`provider/meta.py`, `provider/twilio.py`). Retry with backoff on 5xx; log to `messages_log`.
