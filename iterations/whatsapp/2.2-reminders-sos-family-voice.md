## 3. Tasks

### 3.1 Reminders — `flows/reminders.py`
```
scheduler reminders.next_at → send_template('reminder', [time, text, name],
                              payloads=['rem:done:<id>', 'rem:snooze:<id>'])
                              + TTS voice note in the user's language (send_audio)
rem:done   → mark done → "Well done."
rem:snooze → re-schedule +10 min → "Okay, I'll remind you in 10 minutes."
```

### 3.2 SOS — `flows/sos.py`
```
Triggers: text matching distress.json (HELP / TOLONG / 救命 / உதவி …),
          [Need help] button (checkin_nudge), voice note whose transcript matches.
→ IMMEDIATELY (before anything else):
  "Help is coming. If you can, call 995 now. I'm telling {family} and your neighbours."
  [I'm OK now] [Call my daughter]
→ trigger_sos(user, trigger='whatsapp', lat/lng = last known or home)
→ send_location_request("Please share your location")   # optional; updates sos lat/lng
→ B fan-out → helpers get sos_alert template [I'm on my way] [Call {name}]
helper taps sos:onway:<sos_id> → sos_responses on_way
→ member gets status lines: "Priya is on her way. Ahmad (300 m) is on his way."
sos:ok:<sos_id> → resolve → "Glad you're okay. I've told your Safe Circle."
```
- 995 (SG) / 112 (IN) by user region. Never "monitoring" wording.
- Fan-out timing target < 10 s end-to-end: send concurrently.

### 3.3 Family templates — `flows/family.py`
- `family_missed_checkin` (ladder step 3): "Dad hasn't checked in today." [Call Dad] [I'll check] → Call → `tel:` link or trigger the Voice `family_alert` bridge; I'll check → logs the acknowledgement.
- Invite status: "Dad joined Bricks" (free-form if the window is open, otherwise the push / app).

### 3.4 Escalation hooks (with B)
| Ladder step | WhatsApp action |
|---|---|
| 0 08:00 | `daily_checkin` (2.1) |
| 1 +2 h | `checkin_nudge` [I'm OK] [Need help] → I'm OK stops the ladder; Need help → SOS |
| 2 +3 h | (Voice: are-you-ok call) |
| 3 +4 h | `family_missed_checkin` to family helpers |

Demo timings: +1 / +2 / +3 min with `DEMO_FAST_ESCALATION`.

### 3.5 Voice notes — `media.py`
```
inbound audio → GET media URL (Meta: /{media_id} → url, auth header) → download ogg/opus
  → STT (Gemini / Google, user language) → distress check → flow or orchestrator
  → reply text + optional TTS voice note: TTS → MP3 → convert to ogg/opus (ffmpeg) → upload media → send_audio
  → any change → [Yes] [No] confirmation buttons
delete downloaded audio after transcription (except published stories / thank-yous)
```
