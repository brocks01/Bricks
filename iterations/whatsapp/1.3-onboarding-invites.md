## 3. Tasks

### 3.1 Onboarding flow — `flows/onboarding.py`
```
Trigger: "Hi" / any first message from an unknown number / QR deep link (wa.me/<num>?text=Hi)

step=language  → buttons [English] [Bahasa Melayu] [More…]  → More → list: 中文 · தமிழ்
step=name      → "Lovely! What should we call you? You can type or send a voice note."
                 (voice note → STT; until 2.2 it asks to type, or stores the audio + a placeholder)
step=area      → "Nice to meet you, {name}! Which area do you live in?"
                 (free text → match against the SG area list; confirm if fuzzy: "Toa Payoh?" [Yes] [No])
step=interests → list: Walking · Tai Chi · Cooking · Chess · Music · Gardening · Teaching · Other
step=done      → "You're in! Every morning at 8 I'll ask how you are. Want to see walks near you now?"
                 [Yes please] [Later]
```
- Writes: `users(name, phone, language, area_name, channel_pref='whatsapp', onboarded_by='self', status='active')`, plus interests into `user_memory.summary`.
- **Consent (opt-in)** recorded at the "You're in" step (`06` §5.4).
- Every step is skippable ("Later") except language; resume within 30 min via `wa_sessions`.
- Duplicate phone → link to the existing user (ON-6).

### 3.2 Invite acceptance — `flows/family.py`
```
backend: POST /family/invite → users(status='invited') → send_template('welcome_invite_family',
   lang=senior.language, params=[senior_name, family_name], payloads=['invite:yes:<id>','invite:no:<id>'])

button invite:yes:<id> → accept_invite(id) → users.status='active', family_links.status='accepted',
                         consent record → "Welcome, {name}! {family_name} will be glad. Every morning at 8 I'll ask how you are."
                         → notify family (push / WA): "Dad joined Bricks"
button invite:no:<id>  → "No problem. If you change your mind, just say Hi."  (stays invited, no messages)
```
- Same pattern for `welcome_invite_org` (`invite_org:yes:<id>`) → `org_members` + org Circle (P1 detail in 3.2 / admin).
- **No account activates without the senior's Yes** (ON-5).

### 3.3 Language handling
- Every outgoing message uses `users.language`; buttons and lists are translated too.
