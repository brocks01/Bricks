## 2. Tasks

### 2.1 Meta WhatsApp Cloud API
1. Meta for Developers → create an app (type Business) → add the **WhatsApp** product.
2. The **test number** works immediately for **pre-registered recipient numbers** (max ~5). Add: team phones and senior tester phones.
3. Generate a **permanent system-user token** (not the 24 h temp token): Business Settings → System users → assign the app + WhatsApp permissions.
4. Note `PHONE_NUMBER_ID`, `WABA_ID`, `ACCESS_TOKEN`, `APP_SECRET` in the secret store (`.env`, never committed).
5. Send the default `hello_world` template to a team phone via curl:
```bash
curl -X POST "https://graph.facebook.com/v20.0/$PHONE_NUMBER_ID/messages" \
  -H "Authorization: Bearer $ACCESS_TOKEN" -H "Content-Type: application/json" \
  -d '{"messaging_product":"whatsapp","to":"65XXXXXXXX","type":"template",
       "template":{"name":"hello_world","language":{"code":"en_US"}}}'
```

### 2.2 Meta Business verification
- Start **Business verification** + **display name** approval (can take days). This is needed for a real number and for messaging non-registered recipients.
- Prepare the business documents; decide the display name (working name "Kampung Connect"; the final name is still open).

### 2.3 Twilio WhatsApp Sandbox
- Twilio console → Messaging → Try it out → WhatsApp sandbox → note the **join code** and sandbox number.
- Team phones send `join <code>`.
- The webhook URL will be set in 0.2.
- Limits: users must join first; limited templates / branding. Good for walk-up judges.
