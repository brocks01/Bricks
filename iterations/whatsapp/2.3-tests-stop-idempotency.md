## 3. STOP / START (`06` §5.4)
- Inbound `STOP` (and local equivalents: "BERHENTI", "停止", "நிறுத்து") → `users.wa_opt_out=true` → "Okay, messages are paused. Send START to turn them back on." → the scheduler skips WA (falls back to `channel_pref` alternatives only for **urgent** SOS / family alerts, as agreed with the team).
- `START` → opt back in → confirmation.

## 4. Idempotency and reliability
- `wa_seen(message_id)` checked before routing (from 0.2); button handlers are idempotent too (e.g. a second `join:<id>` → "You're already going.").
- Send retries: exponential backoff on 429 / 5xx; give up after 3; log it.
- Respond to webhooks in < 5 s; heavy work (STT, LLM) in background tasks.
