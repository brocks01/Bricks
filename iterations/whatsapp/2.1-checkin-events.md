## 3. Tasks

### 3.1 Check-in — `flows/checkin.py`
```
08:00 scheduler → send_template('daily_checkin', [name],
                  payloads=['checkin:yes:<date>', 'checkin:no:<date>'])

checkin:yes:<date> → check_in(user, 'yes', channel='whatsapp')
   → "Wonderful! {streak} days in a row. See you tomorrow!"
checkin:no:<date>  → check_in(user, 'no') → s = suggestion (nearest walk ≤ 2 km, next 24 h)
   → "No worries! Walk with {going} neighbours today, {time}, {place}. Join?"
     [Join walk] [Maybe later]       payloads: join:<event_id>, later:<date>
join:<event_id>    → join_event(user, id, channel='whatsapp')
   → "You're going! Here's the group to say hi: {whatsapp_link}  I'll remind you at {time-1h}."
later:<date>       → "Okay. I'm here if you change your mind. Say Menu any time."
no suggestion      → "No worries! Rest well today. I'll ask again tomorrow."
```
- Stale buttons (an old date) → "That was yesterday's question. Today's is coming at 8."
- Answering stops the escalation ladder (B's state) on **any** channel.

### 3.2 Event invites — `flows/events.py`
```
send_template('event_invite', [title, when, place, going_count, host],
              payloads=['join:<id>', 'skip:<id>', 'more:<id>'])
join:<id> → RSVP → confirmation + group invite link
skip:<id> → "No problem."
more:<id> → 2-line description + [I'm going] [Not this time]   (free-form, window open)
```
- Groups: the API can't add people to groups; we send the circle's **invite link** (pasted by the captain) (`06` §5.3).

### 3.3 Free text inside the window
- Text that matches no flow → `orchestrator.turn(channel='whatsapp', text=…)` (from the Voice track 2.1) → reply; confirmation as buttons [Yes] [No] with `confirm:<token>` payloads.
