## 2. Tasks (in priority order)

### 2.1 Weekly progress card (`weekly_progress_card`, P1)
- **B renders** a clean image (Pillow, or HTML → image): name, km walked, walks, streak, thank-yous, a mini route of the best walk (**public, privacy-trimmed polyline**). Brand tokens: white background, near-black text, `#1557B0` accent, Noto Sans (Tamil / SC variants). No emojis.
- Upload to Storage → template image header → "*Your week, Raj:* 8.6 km walked in 4 walks. 5-day streak." [See my walks].
- Scheduler: Sunday 18:00 (+ "fire now" for the demo). Families can forward it to family groups, which is the point.

### 2.2 Walk summary after a walk (P1)
- On `POST /walks` (recorded in the app) for users who opted in: "Morning walk, 2.4 km in 32 min. Well done, Raj." + summary image (route + 3 stats).
- Free-form if the window is open; otherwise template / skip.

### 2.3 Menu (P1)
```
"Menu" (or ms "Menu", zh "菜单", ta "மெனு") → send_list:
  Today · Find events · Reminders · My progress · Help · Language
Today        → get_today summary
Find events  → find_events (3) as buttons [I'm going]
Reminders    → list_reminders + [Add by voice note]
My progress  → get_progress + get_walk_stats sentence
Help         → SOS flow
Language     → language picker → users.language
```

### 2.4 SOS location request (P1)
- In the SOS flow, `send_location_request` ("Please share your location") → inbound `location` → `PATCH sos lat/lng` → helpers' `sos_alert` map link uses it; when nothing is shared, home is used.
- Also for "Find events" near me (optional).

### 2.5 If time allows
- `thank_you_prompt` after events → [Thank] / voice note → endorsement (attendees only; the server checks).
- `weekly_joy_report` to family (respects sharing settings).
