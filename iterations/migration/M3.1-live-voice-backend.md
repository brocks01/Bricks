Phase M3 · Est. **6 h** · Source: [README](README.md) decision "Voice"; shared `backend/app/modules/voice/`, `modules/agent/`; our `assistant/distress.py`, `assistant/executor.py`

| | |
|---|---|

## 4. Tasks

### 4.1 Remove our call agent
- Delete `calls/`, `routers/calls.py`, `assistant/orchestrator.py`, `prerouter.py`, `prompt.py`, `system_prompt.md`,
  `tools.json`, `contract.py`, `routers/assistant.py` and their tests (`test_call_*`, `test_calls_incoming`,
  `test_assistant_*`).
- **Keep and move:** `assistant/distress.py` + `distress.json` → `modules/safety/distress.py`; the action code in
  `assistant/executor.py` (set reminder, join event, today) → `modules/voice/bricks_tools.py`;
  `assistant/replies.json` wording for confirmations → the tools' notes.
- **Keep:** `modules/speech/` (`/v1/assistant/transcribe`, `/v1/tts`): the app's Buddy and Read it out use them.
- Check: WhatsApp does not import any removed file (it does not today).

### 4.2 Safety first (the shared module does not have this)
In the shared module the model answers the moment the person speaks, so our check must run on the live text:
- `session.py`, on every `inputText` frame: join the person's words for the current turn; run
  `safety.distress.match_distress(text, language)`. On a match: raise SOS for the caller (the same service our Help
  button uses), then `note()` the model: "The person may be in danger. Say help is being called, in their language,
  and stay with them." The model is **not** asked whether to raise it.
- The same check on the in-app agent relay (`modules/agent/router.py`) for the `person` text.
- Test with the distress phrases in all four languages (our `distress.json`).

### 4.3 Our actions as tools of the live call
New tools in `modules/voice/bricks_tools.py`, declared like the shared `tools.py` entries (name, hint, declaration),
run **on the server** (the call has no app):

| Tool | Does | Confirmation |
|---|---|---|
| `today` | The person's next reminder and next event (our `today_reply`) | No |
| `set_reminder` | `kind`, `text`, `time`, `repeat` (+ `date` for once) | **Yes**: the hint tells the model to read it back and wait for a yes; the tool takes `confirmed: true` only |
| `join_event` | The next event they are not going to, or one by id from `today` / `events` | **Yes**, the same way |
| `events` | This week's events, short | No |

- A call is for **one person**: the call record carries their `user_id` (M2.1 uuid) and the tools act as them only.
- Tool answers stay short (read aloud on a phone line), in the call's language.

### 4.4 Our system prompt on the shared frame
`logic.build_system_prompt` keeps its safety frame (AI disclosed, no medical advice, never cut someone off). Our brief
replaces the "talk about anything" default: a friendly helper for older people in Singapore, short turns, the person's
language (en, ms, zh, ta), what it can do (the tools above), and that it cannot give medical advice. Web search
(`web_search`, `read_page`) only if both sides want it (it costs a key).

### 4.5 Twilio
- Live calls use different webhooks: `POST /twilio/voice` (TwiML that opens the stream), `POST /twilio/status`,
  `WS /media`. The owner changes the number's voice webhook to `<VOICE_PUBLIC_URL>/twilio/voice` in the console.
- Inbound calls: the shared module only **places** calls. If members should be able to **call in** (our stage demo:
  "call the number"), add an inbound path: Twilio's voice webhook → TwiML with a stream for the caller looked up by
  phone number (`users.phone`). Agree this with the shared side; it is a new capability of their module.
- Trial account: the person presses a key after Twilio's trial message, or the stream never starts (the shared code
  says so in its error).

### 4.6 Act for the right person (after M2.1)
- Outbound: the caller is the person being called (`users.phone` → `user_id`). Inbound (4.5): look up by caller id;
  unknown numbers get a short "please ask your family to add this number" and no tools.

## 8. Risks and fallbacks

| Risk | Fallback |
|---|---|
| Our Gemini key has no Live access or hits its free-tier limit | A billed key (Gemini Live has its own pricing); until then calls stay off and WhatsApp carries reminders |
| Live audio lag on ngrok | Run the backend close to Twilio's region; the shared module already sends audio in 100 ms pieces |
| Inbound calls (4.5) not agreed in time | Outbound only for the demo; the stage call becomes "we call you" |
