### 4.2 Walk engine `lib/walk.ts`
Build the final interface now; only the **source** changes in 2.2.
```ts
type WalkSource = 'simulate' | 'gps';
startWalk({ source, eventId? }): WalkSession
session.onTick(({ elapsed_s, moving_s, distance_m, steps, points }) => void)  // ~1 s
session.pause(); session.resume();
session.finish(): Promise<WalkUpload>   // { points[], steps, started_at, ended_at, event_id? }
```
- **Simulate:** replay the Bishan track at real speed; dev-only 10× toggle.
- Filters: drop accuracy > 30 m, jumps > 50 m in 5 s. Distance = haversine sum.
- Steps: `Pedometer` (expo-sensors), falling back to `distance ÷ 0.7 m`.
- **Auto-pause:** speed < 0.3 m/s for 20 s; `moving_s` kept separate.
- `expo-keep-awake` on S22. Persist points to AsyncStorage every 30 s; on relaunch offer "Save the walk you started".
- Mock `finish()` returns a summary in B's JSON shape (computed locally or from the fixture).

**S21 Check-in** (Monzo + Duolingo mechanics only)
- Title "Did you move yesterday?" + `YesNo`.
- **Yes** → (icon: check) "5 days in a row. Well done."
- **No** → "Want company today?" + one walk `EventCard` + **Join walk** / **Maybe later**. Join → `useRsvp` → S16 (with Join WhatsApp group). **2 taps from S21.**
- After answering, the cards on S12 / S20 disappear. No mascot, flames or guilt messages.

**S26 Reminders** (Monzo list + iOS Reminders)
- Rows: time, text, repeat, **Done**.
- **Add reminder** → **Say it** (mock: canned transcript "Take medicine at 8 every morning" → `ConfirmSheet` "Every day at 8 am: take medicine. Is that right?") **or** the form: What (chips: Medicine, Doctor, Event, Other) → Time (big wheels) → Repeat (Once / Every day / Weekdays).
- On save: schedule a **local notification** (works in Expo Go) with category Done / Snooze. UndoBar on add / delete.
