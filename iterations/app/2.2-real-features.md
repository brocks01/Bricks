## 4. Tasks

### 4.1 Real check-in
- S21 / cards → `POST /checkins {answer, question_key, channel:'app'}` → on "no", show the returned `suggestion` walk.
- Android: handle the notification response for the `checkin` category (Yes / No) and call the API **without opening the app**.
- iPhone: local 08:00 notification → opens S21.
- Any answer (app, WhatsApp, call) stops the server escalation, so the app just refetches `/home/today`.

### 4.2 Real reminders
- S26 → `GET/POST/DELETE /reminders` + a matching local notification (Done / Snooze 10 min).
- Reminders created by **phone call** or **WhatsApp** show up on refresh / foreground (golden path step 5).

### 4.3 GPS walks — `lib/walk.ts` source `gps`
```ts
await Location.requestForegroundPermissionsAsync();             // first walk only, with a reason
if (canRecordInBackground) await Location.requestBackgroundPermissionsAsync();
TaskManager.defineTask(WALK_TASK, ({ data }) => appendPoints(data.locations));
Location.startLocationUpdatesAsync(WALK_TASK, {
  accuracy: Location.Accuracy.BestForNavigation, timeInterval: 5000, distanceInterval: 10,
  foregroundService: { notificationTitle: 'Recording your walk', notificationBody: 'Tap to open' } });
// iPhone (Expo Go): Location.watchPositionAsync in the foreground + keep-awake + "Keep this screen open"
```
- Same filters, auto-pause and 30 s persistence as 1.2. Pedometer for steps. Optional spoken update each km.
- **Finish** → "Saving your walk…" → `POST /walks {points, steps, started_at, ended_at, event_id?}` → render the server summary in S23 (privacy-trimmed route, splits, title, encouragement, walked with).
- Upload failure → keep it locally, show "We'll save it when you're back online", and retry on the next foreground.
- Keep the **Simulate walk** dev toggle for indoor demos.

### 4.4 Real SOS (S28)
- Help → S28 → 5 s countdown → `POST /sos {trigger:'button', lat, lng}` (current location; home if unavailable).
- Live status: poll `GET /sos/{id}` every 3 s (or Supabase realtime): "Priya — on her way", "Ahmad (300 m away) — on his way", "Lim — notified".
- **I'm safe now** → `PATCH /sos/{id} {status:'resolved'}`. Cancel during the countdown → no request.
- Target: "on my way" visible < 10 s after the helper taps (golden path step 6).

### 4.5 S29 Are you OK?
- Opened by the missed-check-in push (Android) or on the next app open while an "are you ok" is pending.
- "Are you okay?" (display) · **I'm OK** (success) · **I need help** (red → S28) · 30 s countdown read aloud.
- I'm OK → the endpoint agreed with backend (e.g. `POST /checkins {question_key:'are_you_ok', answer:'yes'}`) → stops the ladder.

### 4.6 S30 Helper alert
- Opened from the high-priority `sos_alert` push: "Raj needs help" · map with location · time · **I'm on my way** (`POST /sos/{id}/respond {status:'on_way'}`) · **Call Raj** (`tel:`) · "Call 995" link.
- Android only (remote push). iPhone helpers get WhatsApp + a call.

### 4.7 Real Buddy (S36)
```
record → POST /assistant/turn {audio(base64 m4a), language, screen, screen_script}
  ← {transcript, reply_text, reply_audio_url, ui_actions[], done}
show transcript + reply bubble → play reply_audio_url (fallback: device TTS)
for each ui_action:
  navigate {screen, params} → router.push + highlight
  confirm {tool, args}      → ConfirmSheet → second turn with {confirm:{tool,args,answer}}
  start_walk / finish_walk  → lib/walk
  open_sos                  → S28
```
- "Thinking…" + a gentle sound; target: the reply starts in < 2.5 s.
- Offline → the 1.3 keyword matcher + device TTS. Low confidence twice → 3 choice buttons.

### 4.8 Move Along shell (S25, A2.2b)
```tsx
if (!isPostureAvailable) return <FallbackCard />;   // "Camera warm-ups are available on Android" + guided warm-up
<PostureCameraView exercise="sit_to_stand" targetReps={10}
  onReady={...} onTracking={({visible}) => ...}
  onRep={({count}) => { setCount(count); speak(t('move.rep', {count, total:10})); }}
  onCue={({cueId}) => showAndSpeak(t(`posture.cue.${cueId}`))}   // max 1 / 5 s
  onSafetyStop={() => go('stop')} onFinish={(s) => saveSession(s)} onError={...} />
```
- Flow: choose an exercise (2 photo cards) → setup card "Place your phone on a table about 2 metres away so we can see your whole body." (read aloud) → wait for ready + visible → 3-2-1 → reps.
- "6 of 10" at 40pt + soft tick + count read aloud. Safety stop: "Let's stop here and rest." Finish card → `POST /exercise-sessions` → counts toward Thrive "this week".
- Camera permission only when the first warm-up starts, with a one-line reason. The camera is released on unmount.
