### 2.2 Visual pass (vs the Mobbin board)
| Check | Rule |
|---|---|
| Spacing | 4 · 8 · 16 · 20 · 24 · 32 · 48; screen padding 20 |
| Radius | 16 cards / 14 buttons / 999 avatars only |
| Elevation | Flat + 1px border; no shadows |
| Colour | One accent (`#1557B0`); green only for done / going; red only for SOS |
| Icons | Phosphor only; never icon-only; no stray icons |
| Photos | Real local photos everywhere; no clip-art |
| Type | Body ≥ 20pt; no weights < 400; Tamil + 200% font on the golden-path screens |
| Copy | No emojis; plain words; "Members", never "elderly" |
