## 4. Tasks

### 4.1 Create the project on the right SDK
1. Check the SDK version supported by the **current App Store Expo Go** (expo.dev changelog / the Expo Go "About" screen).
2. `npx create-expo-app app -t expo-template-blank-typescript`, then pin `expo` to that SDK in `package.json`. **No SDK upgrades this week.**
3. Install the libraries (all are in Expo Go):
```bash
npx expo install expo-router expo-speech expo-av expo-notifications expo-location \
  expo-sensors expo-haptics expo-localization expo-font expo-secure-store \
  expo-task-manager expo-keep-awake expo-contacts react-native-maps react-native-svg
npm i i18next react-i18next zustand @tanstack/react-query phosphor-react-native @mapbox/polyline
```
4. Before adding **any** other library later: check it is in Expo Go. If it isn't, make it Android-only behind a flag.

### 4.2 Router and tab shell
```
app/app/_layout.tsx                 # providers: QueryClient, i18n, fonts, SafeArea
app/app/(tabs)/_layout.tsx          # Pass It On | Kampung (default) | Thrive
app/app/(tabs)/kampung/index.tsx    # placeholder "Kampung"
app/app/(tabs)/thrive/index.tsx     # placeholder
app/app/(tabs)/pass-it-on/index.tsx # placeholder
app/app/home.tsx · sos.tsx · settings.tsx · dev/components.tsx (placeholders)
```
- Tabs: icon + label always (Phosphor Bold), ≥ 64dp tall, active colour `primary`. Initial route = Kampung.
- Reserve the fixed places now: header slots for **Read it out** (top-left) and **Help** (top-right, red), and a bottom-centre slot for **Tell me**.

### 4.3 Fonts
- Noto Sans, Noto Sans SC, Noto Sans Tamil, in weights 400 / 600 / 700, loaded with `expo-font` and held behind the splash screen.
- Font-family resolver by language (`ta` → Noto Sans Tamil, `zh` → Noto Sans SC, else Noto Sans).

### 4.5 i18n skeleton
- `i18n/en.json` (plus empty `ms.json`, `zh.json`, `ta.json`); key structure `screen.element` (e.g. `home.greeting.morning`).
- `i18next` + `react-i18next`; device language via `expo-localization`, overridden by the user's choice later.
- Fallback language `en`; a missing key logs a warning in dev.

### 4.6 Mock data layer
- `mocks/` folder (filled by B's seed export in 0.2), with React Query hooks reading from it (`lib/mockApi.ts`).
- `USE_MOCKS` flag (true in Phase 1).

### 4.7 Platform flags — `lib/platform.ts`
```ts
export const canUsePosture = !!NativeModulesProxy?.Posture;   // false in Expo Go / iPhone
export const canUseRemotePush = Constants.appOwnership !== 'expo';
export const canRecordInBackground = Platform.OS === 'android' && canUseRemotePush;
```

### 4.8 Builds
- `eas.json` profiles: `development` (dev client, Android), `preview` (APK), with EAS Update channels `demo` / `filming`.
- `eas build --profile development --platform android`, then install on a real arm64 phone.
- `npx expo start` → scan with Expo Go on an iPhone.

## 8. Risks and fallbacks

| Risk | Fallback |
|---|---|
| Expo Go on the App Store is a newer SDK than the template | Create the project with `--template` at the matching SDK; check the App Store version first |
| EAS build queue slow | Start the dev build first thing; use Expo Go on Android meanwhile |
| Posture module breaks the Android build | B keeps it out of the build until its Gradle/Kotlin versions are aligned (`03` §2.1) |
