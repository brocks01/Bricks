## 4. Tasks

### 4.1 Create the project on the right SDK
1. Check the SDK version supported by the **current App Store Expo Go** (expo.dev changelog / the Expo Go "About" screen).
2. `npx create-expo-app app -t expo-template-blank-typescript`, then pin `expo` to that SDK in `package.json`. **No SDK upgrades this week.**
3. Install the libraries (all are in Expo Go):
```bash
npx expo install expo-router expo-speech expo-audio expo-notifications expo-location \
  expo-sensors expo-haptics expo-localization expo-font expo-secure-store \
  expo-task-manager expo-keep-awake expo-contacts react-native-maps react-native-svg
npm i i18next react-i18next zustand @tanstack/react-query phosphor-react-native @mapbox/polyline
```
4. Before adding **any** other library later: check it is in Expo Go. If it isn't, make it Android-only behind a flag.

```
app/src/app/(tabs)/home/index.tsx       # Home: greeting + 3 pillar cards

```
- Tabs: **Home · Pass It On · Kampung · Thrive**, icon + label always (Phosphor Bold; filled when active), ≥ 72dp tall, active colour `primary` plus a tinted background. Initial route = Home.
- Reserve the fixed places now: header slots for **Read it out** (top-left) and **Help** (top-right, red), and a bottom-centre slot for **Tell me**.

### 4.5 i18n skeleton
- `i18n/en.json` (plus empty `ms.json`, `zh.json`, `ta.json`); key structure `screen.element` (e.g. `home.greeting.morning`).
- `i18next` + `react-i18next`; device language via `expo-localization`, overridden by the user's choice later.
- Fallback language `en`; a missing key logs a warning in dev.

### 4.6 Mock data layer
- `mocks/` folder (filled by B's seed export in 0.2), with React Query hooks reading from it (`lib/mockApi.ts`).
- `USE_MOCKS` flag (true in Phase 1).

### 4.7 Platform flags — `lib/platform.ts`
```ts
// NativeModulesProxy and Constants.appOwnership are deprecated in SDK 57.
export const canUsePosture = isAndroid && requireOptionalNativeModule('Posture') != null;
export const canUseRemotePush = isNative && !isRunningInExpoGo();
export const canRecordInBackground = isAndroid && !isRunningInExpoGo();
```

### 4.8 Builds
- `eas.json` profiles: `development` (dev client, Android), `preview` (APK), with EAS Update channels `demo` / `filming`.
- `eas build --profile development --platform android`, then install on a real arm64 phone.
- `npx expo start` → scan with Expo Go on an iPhone.

## 10. Outcome (Tue 10 Nov)

**Built** in `app/` (see `app/README.md`):
- Expo SDK 58 project (TypeScript strict; started on 57, upgraded 11 Nov), Expo Router with routes in `src/app/`.
- Four tabs, **Home first**: Home shows a greeting and the three pillars as large cards (Pass It On, Kampung, Thrive). Each tab is its own stack, so the tab bar (and Home) is always one tap away.
- `<Screen>` frame used by every screen: Read it out (top-left) and Help (top-right, red) on every screen, "‹ Back" on its own row only off a tab's first screen.
- Read It Out engine (core): speaks the screen in the member's language at a slow rate; tap again to stop. Highlighting and Pause / Repeat / Slower stay in 1.3.
- SOS screen that calls 995 from day one (countdown and Safe Circle in 1.2).
- Tokens, Noto Sans + Noto Sans Tamil (3 weights each), system font for Mandarin; en / ms / zh / ta strings for the shell (non-English are drafts until wave 1 review).
- Data layer: wire types, mock and HTTP clients behind one interface, React Query with refetch on app foreground.
- Persisted settings (language, read-out rate) that never flash the wrong language at startup.
- Guard-rail lint rules (no hex colours, no `Platform.OS`, no raw `Text` in screens), Prettier, 67 tests including the real router, contrast and translation-completeness tests. `npm run check` is green; `expo-doctor` 21/21; Android and iOS bundles export.

**Changes from this plan**
- `expo-av` → `expo-audio` (expo-av is no longer in Expo Go). Platform flags use `requireOptionalNativeModule` and `isRunningInExpoGo` (the old APIs are deprecated).
- Routes live in `app/src/app/` (Expo's `src/` convention).
- Settings and `dev/components` routes are created in their own iterations (1.3 and 0.2), not as empty placeholders.
