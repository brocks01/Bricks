### 4.2 Mock hooks
Names and shapes mirror the backend endpoints, so 2.1 only swaps the `queryFn`.

| Hook | Mirrors | Notes |
|---|---|---|
| `useMe()` | `GET /me` | name, language, area |
| `useToday()` | `GET /home/today` | `{checkin:{pending}, next_event, next_reminder}` |
| `useEvents({category, when})` | `GET /events` | filter chips → params |
| `useEvent(id)` | `GET /events/{id}` | host, attendees, going_count, whatsapp_link, my_rsvp |
| `useRsvp(id)` / `useCancelRsvp(id)` | `POST/DELETE /events/{id}/rsvp` | optimistic; state in zustand so it survives navigation |
| `useCreateEvent()` | `POST /events` | appends to the in-memory list |
| `useCircles()` / `useCircle(id)` / `useJoinCircle(id)` | `/circles` | `my` and `near_me` sections |

**Decisions made (please review)**
| Decision | Why |
|---|---|
| **Home = greeting → Today (check-in, next event, next reminder) → the three pillars.** The four shortcut tiles from the S12 sketch are dropped. | The pillar cards already lead everywhere; tiles would repeat them and double the choices on the first screen. |
| **Event details (S15) and You're going (S16) open over the current tab** (`/event/[id]`, `/going/[id]`). | Back always returns exactly where the member came from (Home, Happenings or a Circle), with no surprise tab switch. |
| **Kampung tab opens with a "My Circles" card, then Happenings.** | My Circles (S18) needs a way in now that the Home tiles are gone. |
| **The check-in works now (minimal):** Yes → "Well done, 6 days in a row"; No → "Want some company today?" + a walk you can join in one tap. | A Yes / No that did nothing would be a dead control. The full S21 screen and streak bars stay in 1.2. |
| **The reminder's Done works** (marks it done, says "Done. Well done."). | Same reason; the full reminders screen is 1.2. |
| **Start Something is 5 one-question steps + a preview:** What → Which day (next 7 days by name) → What time (8 sensible times, past ones hidden) → Where (4 local choices or type) → WhatsApp link (optional, validated) → Check and publish. | Every answer is a big tap; typing is only an extra. No date picker (hard for seniors); "Pick another date" can come later. |
| **No "Say it" (voice) button yet** on Start Something, and **no Translate button** on event details. | Both need Buddy / translation (1.3+). A button that does nothing is worse than no button. |
| **One app-wide Undo bar** that follows you to the next screen. Undo on "You're going" closes that screen and puts the event back. | Rule 7 (forgive mistakes) without making each screen manage its own bar. |
| **"I can't go any more" asks first** (ConfirmSheet), on event details. | Giving up a place is easy to do by accident. |
| **Changing a Happenings filter keeps the list on screen** until the new one arrives. Tapping the chosen filter again shows everything. | No flashing spinner; no hidden "clear" control. |
| **Read it out never disappears**, even while a screen loads (it reads the title). | The fixed controls must always be in the same place. |
| **Seed fix: Lim (Circle captain) hosts the Morning walk**, not Raj. | The golden path has Raj *joining* this walk; a host can't join their own event. |

**Data:** the mock backend (`src/mocks/db.ts`) is an in-memory version of the API with the 5 personas, 3 Circles and 8 events around Bishan / Toa Payoh, times relative to now. The request/response shapes it implements (`EventDetail`, `Today`, `CheckinResult`, `CircleList`, `CircleDetail`, `NewEvent` in `src/api/types.ts`) and the HTTP routes in `src/api/client.ts` are **proposals for the backend contract**: please confirm with backend before 2.1.
