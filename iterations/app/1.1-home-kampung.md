### 4.2 Mock hooks
Names and shapes mirror the backend endpoints, so 2.1 only swaps the `queryFn`.

| Hook | Mirrors | Notes |
|---|---|---|
| `useMe()` | `GET /me` | name, language, area |
| `useToday()` | `GET /home/today` | `{checkin:{pending}, next_event, next_reminder}` |
| `useEvents({category, when})` | `GET /events` | filter chips → params |
| `useEvent(id)` | `GET /events/{id}` | host, attendees, going_count, whatsapp_link, my_rsvp |
| `useRsvp(id)` / `useCancelRsvp(id)` | `POST/DELETE /events/{id}/rsvp` | optimistic; state in zustand so it survives navigation |
| `useCreateEvent()` | `POST /events` | appends to the in-memory list |
| `useCircles()` / `useCircle(id)` / `useJoinCircle(id)` | `/circles` | `my` and `near_me` sections |
