**Rules every component follows**
- All sizes and colours from `tokens.ts`; radius 16 (cards) / 14 (buttons); 1px border, no shadow.
- Icons: Phosphor Bold on buttons / tabs, Regular inline, 28–32dp, **always with a label**.
- Text never truncates to "…" for primary labels. It wraps (Tamil is long).
- Touch targets ≥ 64×64dp, ≥ 16dp apart.
- Motion: 150–200 ms fades / slides only.
- `accessibilityLabel` + `accessibilityRole` on every interactive element.

**Design decisions for seniors (please review)**
- **One fact per line.** EventCard and ClubCard show when / where / who as separate lines with an icon each ("Tomorrow, 7 am" / "Bishan Park, Gate 2" / "12 going"), not one dense "·" line. Easier to scan and wraps cleanly in Tamil.
- **Two separate touch targets per card.** Tapping the card body opens details; the button does the action. They are never nested, so screen readers reach both.
- **"You're going" replaces the button** once joined (green tick on a light-green tint), so a card never offers an action that's already done.
- **Yes / No stack** when text is 150% or larger, so neither label gets squeezed. No is a calm outline with an X, never red.
- **Sheets never close by tapping outside.** Only their own labelled buttons (or Android Back) close them, so an accidental tap can't lose what someone said.
- **Voice notes have a worded Play / Pause button**, a waveform that fills as it plays, the length as "0:12", and the transcript underneath. Playing a note stops Read It Out so voices never overlap.
- **Undo bar** is dark (stands out without a shadow), is announced to screen readers, stays 8 s, and its Undo is a full 64dp target.
- **StatusBanner has no red tone**: red stays reserved for SOS.
- **Tiles grow taller** instead of cutting text at large sizes; tiles and circle banners fall back to a large category icon when there is no photo (never clip-art).
- **Mandarin plurals / Tamil plurals** follow each language's grammar (tested).

**Data shapes** `EventSummary` and `CircleSummary` were added to `src/api/types.ts` as a **proposal for the backend contract**; confirm with backend at the start of 1.1. The backend seed export for `mocks/` (entry criterion) has not arrived yet; the gallery uses its own sample content.
