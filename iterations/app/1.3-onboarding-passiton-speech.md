## 5. Tasks

### 5.1 Read It Out — `lib/readout.ts` (S37)
```ts
useReadOut(() => [{ text: t('s15.readout', {...}), targetRef? }]);
// engine
Speech.speak(text, { language: voiceFor(lang), rate: 0.85, onDone, onStopped });
const voiceFor = { en: 'en-SG', ms: 'ms-MY', zh: 'zh-CN', ta: 'ta-IN' };
```
- On startup run `Speech.getAvailableVoicesAsync()`. If no `ms` / `ta` voice exists, play pre-generated audio from the backend `/tts` for P0 phrases.
- Reading order: **where you are → content → what you can do.** Highlight `targetRef` while speaking.
- Bottom bar while reading: **Pause · Repeat · Slower**. Tapping a card reads only that card.
- Settings: auto-read (default off), speed (default slow), voice (male / female).

### 5.2 Mock Buddy — `lib/voice.ts` (S36)
```
Tell me → ListeningSheet ("Listening…", transcript 24pt, Stop)
  → record (expo-audio, max 15 s, stop on 1.5 s silence)
  → transcript (see below) → intent = matchKeywords(transcript, lang)
  → reply bubble (large) + device TTS + Play again
  → change? → ConfirmSheet → Yes → perform → UndoBar
  → navigate / highlight visibly
```
- **Transcript source in Phase 1** (Expo Go has no device STT API): (a) a hidden dev panel of pre-set utterance chips per language that the facilitator taps, **or** (b) the backend `/assistant/turn` stub returning a canned transcript. Pick the reliable one by 10:00.
- Intents per language: **today** · **join** · **check in yes / no** · **remind me** · **start / stop walk** · **help** · **open profile**.
- **help** → open S28 immediately, with no confirmation.

**Decisions made (please review)**
| Decision | Why |
|---|---|
| **Read It Out speaks one sentence at a time.** Pause stops; Carry on and Repeat restart the current sentence; Slower slows by 0.1 and repeats it | Android's speech engine can't pause mid-sentence; sentences make all three buttons work the same on both phones. |
| **Each screen stops only its own reading** when it closes | Otherwise the screen being left cut off the next screen's announcement (SOS) or Buddy's answer. This was a real bug, found by the new tests. |
| **"Tap a card to read just that card" is left out** | A tap must always do the same thing (open the card). Repeat covers hearing something again. |
| **Voice choice (male / female) is left out** | Phones don't report a voice's gender reliably. Speed and Auto-read are in Settings. |
| **Tell me sits at the bottom of every screen without its own action bar**, and on the walk screen | One primary action at the bottom. On the walk screen it allows "stop the walk" hands-free. Not shown on SOS or during onboarding. |
| **On mock data, Buddy shows "Demo: tap what was said"** (one phrase per intent, in the app language); it still records | Expo Go has no speech-to-text. The facilitator taps what was said, so the test is of the flow, as §9 allows. With a real speech service the box never appears and the recording goes to `/assistant/transcribe`. |
| **Buddy asks before any change** (join, check-in, reminder); **reading and going places never ask**; **help never asks** | Monzo-style confirmation for changes; no friction for looking; SOS must be instant. |
| **Language buttons move on straight away** (no separate Next) | One tap; the next screen has Back. |
| **Every onboarding step is skippable**: with no answer, Next reads "Skip for now" | ON-7, without a second button competing with Next. |
| **Onboarding answers are saved together at S7**, and progress is kept on the phone | Closing the app mid-way resumes on the same step; nothing half-done reaches the server. |
| **Interests use icons, not photos**; "Other by voice" is left out | No licensed photos yet; interests are fixed keys so the app can translate them. |
| **Safe Circle: the phone's own contact picker, or type a name and number**, with a Family choice per person and Remove + Undo | No in-app list of all contacts (privacy); typing always works, even if contacts are refused. |
| **S10: "Set a reminder for Dad" appears only after Dad says yes**; Simple Mode shows as "coming soon" | Consent first (ON-5). |
| **On mock data, a "Demo: Dad says yes" button** stands in for the parent's WhatsApp reply | The real yes happens outside the app. |
| **A skill without a date is "Whenever someone asks"** and doesn't become an event; with a date it does (PO-4) | Not everything is a scheduled class. |
| **Paid sessions show as "coming soon"**; Free is fixed | As specified. |
| **Thank-yous: one-tap Thank, or record ≤ 20 s → listen → Send**; no Undo | People hear their message before sending; thank-yous are only ever kind. |
| **Profile: two Chips (What I've Given / What I Can Share)** switch the section below | "Two clear buttons instead of tabs" (S33). |
| **Reminders get "Say it instead"**, which opens Buddy | Restores the 1.2 voice route (T7 of 1.2) now that Buddy exists. |
| **Settings → Sign out resets the demo** on mock data | The filming team needs a reliable "start again". |
| **The user-content Translate button is left out** until `/translate` exists (2.2) | No placeholder buttons. |
| **Sample voice notes are synthetic English recordings** (`assets/audio`, ~740 KB) | Real seed recordings replace them. |
