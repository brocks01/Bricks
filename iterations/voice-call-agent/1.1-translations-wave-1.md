## 3. Tasks

### 3.1 Translate
- Screens S12, S14–S19: greeting, cards, tiles, filters, event details, "You're going", Start Something steps, circles, empty states, read-out scripts.
- **Style rules (`02` §8–§9):**
  - Everyday words, not formal / government register.
  - Dates as "Tomorrow, 7 am" equivalents (e.g. ms "Esok, 7 pagi", zh "明天上午7点", ta "நாளை காலை 7 மணி").
  - "Join walk", not "RSVP". "Members", never "elderly".
  - Interpolation placeholders kept exactly: `{{name}}`, `{{count}}`, `{{time}}`.
  - Plurals via i18next `_one` / `_other` where needed (ms / zh / ta mostly don't inflect, but keep the keys).
- Read-out scripts: write them to be **heard**: short sentences, no abbreviations ("km" → "kilometres").

### 3.2 Length check
- Flag any Tamil string > 1.5× its English length to the app track (Tamil is designed for first; buttons wrap).

### 3.3 Native-speaker review
- Send a sheet (key · English · translation · context / screenshot) to the reviewers. Turnaround the same evening.
- Track `reviewed: yes/no` per key in the sheet.

## 7. Outcome (Wed 11 Nov)

**Scope.** 182 English strings on Home, Kampung, event details, You're going, Start Something,
Circles, plus shared buttons, dates and units (`app/src/i18n/locales/{ms,zh,ta}.json`; these were
written with the app screens).

**Automated checks.** Already in `locales.test.ts`: same keys as English, the plural forms each
language needs, every `{{placeholder}}` kept, no empty strings, no emojis. Added by hand this
round, all clean: nothing left in English except names (Bricks, Kampung, WhatsApp) and pure
layout templates; no "RSVP" / "elderly" / "warga emas" / "老年人" / "முதியோர்".

**First-pass review fixes**
- Tamil: "படி 2 / 5" was read aloud as a slash. It is now "படி 2, மொத்தம் 5 படிகள்" (also in
  reminders, onboarding, family and the step label).
- Malay: Play button "Main" (play a game) → "Mainkan" (play audio).
- Chinese: the Start Something hint "麻将下午或蜡染绘画" → "例如：下午打麻将，或者学画蜡染".

**Review sheet:** [docs/translations/wave-1-review.xlsx](../../docs/translations/wave-1-review.xlsx).
One tab per language (key, screen, read aloud?, English, translation, length vs English, our
question, OK? yes / no, better wording) and a "How to review" tab with the rules, an example and
progress counts. 8 questions for reviewers, for example: Malay "Saya pergi" vs "Saya ikut",
"Bulatan" vs "Kumpulan"; Chinese generic "不是"; Tamil technical words for Undo and Play.

**Tamil length.** 44 of 182 lines are over 1.5× English. The app is designed for Tamil first
(buttons wrap, no fixed widths); the sheet marks them pink so reviewers can offer shorter wording.

**For wave 2 (1.2).** Units ("min", "km", "நிமி", "கி.மீ.") are fine on screen but must never be
read aloud as short forms: check the walk screens' read-outs.

**Language review (Wed 11 Nov, second pass).** All 8 questions answered and every line re-read:
- Malay: "Saya pergi" (can sound like "I'm leaving") → "Saya ikut", also "{{count}} orang ikut"
  and the read-outs; Circle "Bulatan" (a drawn circle) → "Kumpulan" everywhere in wave 1;
  "menegur" (can mean scold) → "bertegur sapa"; "tidak dapat pergi lagi" → "tidak jadi pergi";
  hours and seconds written out (jam, saat); a more natural read-out bar label and hints.
  Kept: "Batal" for Undo (on the undo bar it cancels what was just done).
- Chinese: No button "不是" → "否" (pairs with "是" for any question; also in the check-in prompts);
  "有没有活动一下身体"; Circle captain "队长" → "组长"; "一起种花种菜"; "给孩子们讲故事".
- Tamil: Undo "செயல்தவிர்" → "ரத்து செய்"; Play "இயக்கு" → "கேளுங்கள்" (listen), Pause
  "சற்று நிறுத்து" (also the voice-note button); afternoon greeting "மதிய வணக்கம்" → "வணக்கம்";
  "1 நபர் வருகிறார்"; "வரப்போவதில்லை"; units written out (நிமிடம், வினாடி); a sandhi fix.
- App tests: 495 pass (one Tamil plural test updated to the new wording).
- The sheet's brown notes now say what changed and why, so a native speaker can confirm in one pass.

**Left open, on purpose**
- Malay evening greeting: the app says "evening" from 5 pm; "Selamat malam" really fits after dark
  (5 to 7 pm is "petang"). Fixing it means a separate night greeting in every language; not worth
  it for now.
- Safe Circle is still "Bulatan Selamat" in Malay (SOS screens, wave 2): decide in 1.2 whether it
  becomes "Kumpulan Selamat" to match.
