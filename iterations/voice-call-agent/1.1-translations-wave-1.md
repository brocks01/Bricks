## 3. Tasks

### 3.1 Translate
- Screens S12, S14–S19: greeting, cards, tiles, filters, event details, "You're going", Start Something steps, circles, empty states, read-out scripts.
- **Style rules (`02` §8–§9):**
  - Everyday words, not formal / government register.
  - Dates as "Tomorrow, 7 am" equivalents (e.g. ms "Esok, 7 pagi", zh "明天上午7点", ta "நாளை காலை 7 மணி").
  - "Join walk", not "RSVP". "Members", never "elderly".
  - Interpolation placeholders kept exactly: `{{name}}`, `{{count}}`, `{{time}}`.
  - Plurals via i18next `_one` / `_other` where needed (ms / zh / ta mostly don't inflect, but keep the keys).
- Read-out scripts: write them to be **heard**: short sentences, no abbreviations ("km" → "kilometres").

### 3.2 Length check
- Flag any Tamil string > 1.5× its English length to the app track (Tamil is designed for first; buttons wrap).

### 3.3 Native-speaker review
- Send a sheet (key · English · translation · context / screenshot) to the reviewers. Turnaround the same evening.
- Track `reviewed: yes/no` per key in the sheet.
