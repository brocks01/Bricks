## 3. Tasks

1. Create the Twilio account; upgrade from trial if trial restrictions block calls to unverified numbers (or verify the team's numbers).

### 3.2 Webhook + tunnel
```bash
ngrok http 8000   # → https://<id>.ngrok-free.app
# Twilio console → Phone number → Voice → "A call comes in" → POST https://<id>/voice/incoming
```

### 3.3 Hello-world handler (`channels/voice/handlers.py`)
```python
@router.post("/voice/incoming")
async def incoming(request: Request):
    validate_twilio_signature(request)            # X-Twilio-Signature
    r = VoiceResponse()
    for lang in ("en", "ms", "zh", "ta"):
        r.play(audio_url(f"hello.{lang}.mp3"))
    return Response(str(r), media_type="application/xml")
```
