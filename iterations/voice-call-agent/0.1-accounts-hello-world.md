### 3.3 Hello-world handler (`channels/voice/handlers.py`)
```python
@router.post("/voice/incoming")
async def incoming(request: Request):
    validate_twilio_signature(request)            # X-Twilio-Signature
    r = VoiceResponse()
    for lang in ("en", "ms", "zh", "ta"):
        r.play(audio_url(f"hello.{lang}.mp3"))
    return Response(str(r), media_type="application/xml")
```
