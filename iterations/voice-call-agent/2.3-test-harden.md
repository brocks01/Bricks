## 2. Test suites

| Suite | Method | Pass |
|---|---|---|
| **Intents** | 20 utterances × 4 languages × each P0 intent (navigate, today, find / join, check-in, reminder, progress, walk stats, emergency) through `orchestrator.turn()` (text) + a sample through real audio | **≥ 85%** correct tool + args per intent |
| **Distress** | "help", "I fell", "tolong", "救命", "உதவி" + variants from `distress.json`, via Buddy, call and WhatsApp | **100%** trigger SOS |
| **Senior call test** | Up to 5 people (seniors or older proxies) call and do a check-in + join a walk | < 2 min, without help |
| **Escalation dry run** | 1-minute timings: check-in → reminder → call → family alert | Fires **in order**; stops on any answer |
| **Noise** | TV / background noise at a moderate level during calls and Buddy | Still works (or DTMF / choices rescue it) |

### 2.1 Utterance set — `channels/voice/tests/utterances/{lang}.yaml`

```yaml
- intent: set_reminder

```
- A runner script prints a per-intent accuracy table; keep it for re-runs in 3.2 / 3.3 after any prompt change.

## 3. Hardening
- Timeouts: Gemini > 3 s → keyword fallback; TTS failure → `<Say>`.
- Twilio webhook signature validation on all `/voice/*` routes.
- Idempotent status callbacks (keyed by `CallSid`).
- Rate-limit outbound calls per user (max 3 per hour, except SOS).
- Logs: no audio, no health card, phone numbers hashed.
