## 3. Tasks

### 3.1 Orchestrator — `backend/agent/orchestrator.py`
```python
async def turn(user, channel, language, text=None, audio=None, screen=None,
               screen_script=None, confirm=None) -> TurnResult:
    transcript = text or await stt(audio, language)          # Gemini audio or Google STT
    if is_distress(transcript, language):                     # deterministic, pre-LLM
        sos = await tools.trigger_sos(user, reason=transcript)
        return reply(t("sos.confirm", language), ui=[{"type": "open_sos", "id": sos.id}])
    if confirm:                                               # second turn of a confirmation
        return await execute_confirmed(user, confirm)
    ctx = build_context(user.memory_summary, screen, screen_script, channel)  # never the health card
    resp = await gemini.generate(system=SYSTEM_PROMPT.format(**ctx),
                                 tools=tools_for(channel), messages=[transcript])
    for call in resp.function_calls:
        if call.name in MUTATING:
            return needs_confirmation(call)                   # ui_action: confirm
        result = await tools.run(user, call)
        resp = await gemini.continue_with(result)
    return reply(resp.text, ui=resp.ui_actions)
```
- `tools_for(channel)`: calls / WhatsApp exclude `navigate`, `read_screen`, `start_walk`, `start_warmup`.
- STT languages: `en-SG`, `ms-MY`, `cmn-Hans-CN`, `ta-IN` (or `ta-SG`).
- **Reply rules** enforced after generation: ≤ 2 sentences (truncate / re-ask), in the user's language, no medical advice.
- TTS (Google Cloud) → MP3 in Storage, cached by `hash(text, voice)` → `reply_audio_url`.

### 3.2 Endpoint — `POST /assistant/turn`
- Input: `{audio? (base64 m4a) | text?, language, screen?, screen_script?, confirm?: {tool, args, answer}}`.
- Output: the 0.2 response contract.
- Auth: Supabase JWT (app). The call / WA handlers call `orchestrator.turn()` directly.

### 3.3 Confirmation pattern
```
Turn 1: "remind me to take medicine at 8 every morning"
  → {reply_text: "Every day at 8 am: take medicine. Is that right?",
     ui_actions: [{type: confirm, tool: set_reminder, args: {...}}], done: false}
Turn 2: confirm {tool: set_reminder, args, answer: yes}
  → executes → "Done. I'll remind you every day at 8 am." done: true
answer: no → "Okay, I won't set it. What would you like instead?"
```

### 3.4 Memory merge (with B)
- After a conversation ends (app sheet closed, call ended, WA session expired): a short Gemini call merges durable facts into `user_memory.summary` (interests, preferences, notes, upcoming). Never long history; never the health card.

### 3.5 Move the inbound call loop onto the orchestrator
- `/voice/turn` → `orchestrator.turn(channel='call', text=SpeechResult)`. Keep the 1.3 keyword path as the **fallback** when Gemini errors or times out (> 3 s).

### 3.6 Unit tests
- 10 English utterances per P0 intent → expected tool + args (pytest, Gemini calls recorded / mocked for CI).
