## 3. Tasks

### 3.1 Inbound in Malay, Mandarin, Tamil
- Language from `users.language` (known caller) or the DTMF menu (unknown caller).
- `<Gather language="ms-MY" | "cmn-CN" | "ta-IN">`, using the support findings from 0.1.
- **Weak language → fallback:** `<Record maxLength="10" playBeep="false" action="/voice/recorded">` → download the recording → our STT (Gemini / Google) → orchestrator → reply → **delete the recording** (Twilio API).
- Unknown caller: language → short onboarding (name → area → interests) → `users(status='active', onboarded_by='self', channel_pref='call')` → SMS / WhatsApp welcome ("A family member can also set you up.").

### 3.2 Outbound calls — `channels/voice/calls.py`
```python
def place(call_type, user, **params):
    return twilio.calls.create(
        to=user.phone, from_=TWILIO_NUMBER,
        url=f"{BASE}/voice/outbound/{call_type}?user={user.id}&{urlencode(params)}",
        status_callback=f"{BASE}/voice/status", status_callback_event=["completed"],
        machine_detection="Enable")
```

| Type | Trigger (scheduler / SOS) | Script | Result handling |
|---|---|---|---|
| `checkin` | 08:00 for `channel_pref=call` | "Good morning Mdm Tan, it's Buddy. Did you move yesterday? Say yes or no." → No → walk offer | `check_in`; join → `join_event` |
| `reminder` | `reminders.next_at` | "Hi Mdm Tan, a reminder: take your medicine. Say 'done' when you have." | Done → mark it done |
| `event_reminder` | 1 h before start | "Your walk starts at 6 pm at Block 45 park. See you there!" | — |
| `are_you_ok` | Check-in +3 h unanswered (all users) | "Hi Raj, we haven't heard from you today. Are you okay? Say yes, or say help." | Yes → stops the ladder · help → `trigger_sos` · no answer after 2 tries → family alert |
| `sos_helper` | SOS fan-out | "This is Bricks. Raj pressed Help near Block 123. Say 'coming' if you can go, or press 1." | `sos_responses.status='on_way'` |
| `family_alert` | Check-in +4 h unanswered | "Hi Priya, your dad hasn't checked in today. Say 'call him' to connect now." | "call him" → `<Dial>` the senior |

- **Retry policy:** unanswered → retry once after 10 min (**1 min** with `DEMO_FAST_ESCALATION`). Voicemail (`AnsweredBy=machine_*`) → short message + a WhatsApp text.
- `/voice/status` callback → records the outcome; tells the ladder whether to move on.

### 3.3 Identity & safety (`05` §3.3)
- Caller ID must match a registered phone; otherwise the unknown-caller path runs.
- **Sensitive actions** (change Safe Circle, family links, phone number) need the **4-digit PIN** set by the member / family (`<Gather input="dtmf" numDigits="4">`). Without it: "Please ask Priya to do that in the app."
- Never read health-card details aloud on outbound calls.
- Don't act on a second voice in the background for sensitive actions.
- Log every call (`messages_log`), store the transcript, delete the audio.

### 3.4 Pre-generated TTS library — `channels/voice/tts_library.py`
- At build / deploy: for every fixed prompt × 4 languages → Google Cloud TTS → MP3 in Storage → manifest `{prompt_id, lang} → url`.
- Runtime: `<Play>` fixed segments + live TTS only for dynamic slots (names, event titles, times). Concatenate `<Play>` verbs.
- Choose a voice per language and keep it consistent (warm, slower rate ~0.9).
