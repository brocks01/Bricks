## 2. Tasks

### 2.1 System prompt — `prompts/system.md`
```
You are Buddy, a friendly helper in Kampung Connect for members aged 50+.
- Speak in the member's language: {language}. Use simple everyday words.
- Reply in at most 2 short sentences. Speak warmly; use their name.
- You can ONLY act through the provided tools. Never invent events or data.
- Before any change (join, cancel, reminder, create), confirm in one sentence and wait for yes.
- If the member says words like "help", "fall", "pain", "can't breathe", "emergency":
  call trigger_sos immediately and tell them help is coming and to call 995 if they can.
- No medical advice, no money, no drafting messages, no long chit-chat.
  If they want company, suggest a real event or circle.
- If you don't understand twice, offer 2–3 choices.
Member memory: {user_memory.summary}
Current screen (app only): {screen_name} — {screen_script}
Channel: {channel}   # app | whatsapp | call — calls/WhatsApp have no navigate/read_screen
```
- English handles Singapore-accented and mixed-language speech. The prompt is written in English, and the model answers in `{language}`.

### 2.2 Tool schemas — `shared/tools/schemas.json` (Gemini function declarations)

| Tool | Args | Mutating (needs confirmation) | Channels |
|---|---|---|---|
| `get_today` | – | no | all |
| `find_events` | `category?`, `when?` (today / tomorrow / weekend), `near?` | no | all |
| `join_event` | `event_id` | **yes** | all |
| `cancel_event` | `event_id` | **yes** | all |
| `check_in` | `answer` (yes / no) | no (the answer *is* the confirmation) | all |
| `set_reminder` | `text`, `time` (HH:MM), `repeat?` (once / daily / weekdays) | **yes** | all |
| `list_reminders` / `delete_reminder` | `id` | delete: **yes** | all |
| `get_progress` | `period` (week) | no | all |
| `get_walk_stats` | `period` (week / month), `last?` | no | all |
| `start_walk` / `finish_walk` | – | no → `ui_action` | app |
| `start_warmup` | `exercise?` | no → `ui_action` | app (Android) |
| `create_event` | `title`, `when`, `where` | **yes** | all (P1) |
| `offer_skill` | `title`, `availability`, `place` | **yes** | all (P1) |
| `record_story` / `send_thanks` | `audio` | **yes** | app / WA (P1) |
| `trigger_sos` | `reason?` | **no, immediate** | all |
| `navigate` | `screen`, `params` | no → `ui_action` | app |
| `read_screen` | – | no | app |
| `set_language` | `lang` | no | all |

**Confirmation pattern:** a mutating tool returns `{needs_confirmation: true, summary}` unless the turn carries `confirm: {tool, args, answer: 'yes'}`.

### 2.3 Response contract (agreed with A)
```json
{
  "transcript": "remind me to take medicine at 8 every morning",
  "reply_text": "Every day at 8 am: take medicine. Is that right?",
  "reply_audio_url": "https://.../tts/abc.mp3",
  "ui_actions": [{"type": "confirm", "tool": "set_reminder",
                  "args": {"text": "Take medicine", "time": "08:00", "repeat": "daily"}}],
  "done": false
}
```
`ui_actions.type` ∈ `confirm | navigate | highlight | start_walk | finish_walk | start_warmup | open_sos | choices`.
