## 4. Q&A slide: channel architecture
- Three doors, one brain: App (REST) · WhatsApp (webhook) · Calls (Twilio webhook / stream) → **one orchestrator** → **one fixed tool registry** → one DB and one `user_memory`.
- Safety: deterministic distress check before the LLM; confirmation on every change; health card never sent to the LLM; audio deleted after transcription.
- Cost: WhatsApp is the default; calls only for `channel_pref=call` and escalations; pre-generated TTS.
- Roadmap: Gemini Live natural calls; SEA-LION (text) / MERaLiON (speech); Indian numbers via Exotel / Plivo.
