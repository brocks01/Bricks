# Wisdom

**Wisdom connects generations to live a whole life together.** Elders pass on what 30 to 50 years taught them; younger people learn, help and grow; the bonds between them make a society stronger. *Every life has something to teach.*

Built for the Singapore–India Hackathon 2026 (raiSE, Social Innovation and Inclusive Development).

- **Three tabs:** Wisdom (the round centre button: experience shared in the person's own words), Communities (people near you, events that repeat, a reason to show up) and Marketplace (what experience and craft can earn, market days).
- **One agent** on a phone call, Telegram, WhatsApp, SMS and the app, with one memory and one set of abilities.

## Run it
See `team-docs/03-technical/architecture.md`. In short: `python backend/run.py` for the API, and `cd app && EXPO_PUBLIC_API_URL=http://localhost:8000 npx expo start --web --port 3000` for the app. How we work together: `CONTRIBUTING.md`. Instructions for coding agents: `AGENTS.md`.
